# Roadmap

## ✅ Hito 1 — Setup Inicial
- Vite + React + TypeScript + Tailwind
- Sidebar colapsable + Layout
- Tema oscuro morado
- Componentes UI base

## ✅ Hito 2 — Dashboard Visual
- WorkspaceContext (Personal / Fernando ADS)
- KPI cards, gráficas con Recharts
- Mock data aislada por workspace
- Dashboard con todos los widgets

## ✅ Hito 3 — Base de Datos + Movimientos
- PostgreSQL + Prisma ORM
- Express REST API
- Workspaces, Cuentas, Categorías, Transacciones
- Dashboard conectado a datos reales
- Páginas Ingresos, Gastos, Movimientos, Cuentas
- TransactionModal: crear y editar movimientos
- TanStack Query para invalidación automática
- Tests de reglas financieras (Vitest)

## 📋 Hito 4 — Compromisos y Pendientes
- Gastos fijos recurrentes
- Nómina del equipo
- Deudas con plan de pago
- Página de Pendientes funcional

## 📋 Hito 5 — Fernando ADS Completo
- Clientes con CRM básico
- Facturación y cobros
- Cuentas por cobrar
- Reportes del negocio

## 📋 Hito 6 — Cashea + SAN
- Sistema de cuotas Cashea
- Sistema de ahorro SAN (número)
- Calendario de pagos

## 📋 Hito 7 — Transferencias
- Transferencia entre cuentas (modelo Transfer)
- Sin afectar INCOME/EXPENSE

## 📋 Hito 8 — Autenticación
- Login / JWT
- Sesiones por usuario
- Workspaces por usuario

## 📋 Hito 9 — Reportes
- Reportes mensuales PDF/CSV
- Comparativos año a año
- Proyecciones

## 📋 Futuro
- Importación Excel
- Integración bancaria (Plaid)
- IA para categorización automática
